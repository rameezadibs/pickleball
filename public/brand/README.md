# SPARK Brand Assets

Drop the original **SPARK PICKLEBALL** logo file into this folder (for example, `spark-logo.svg` or `spark-logo.png`) and set `siteConfig.brand.logoSrc` in `src/config/siteConfig.ts` to `'/brand/spark-logo.svg'` (or `'/brand/spark-logo.png'`).

`BrandLogo.tsx` renders the exact asset untouched via `<img />` with `object-contain` and zero CSS recoloring or distortion filters.
